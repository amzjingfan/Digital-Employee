## 1. 先看全局

Joukir 继承 StaffDeck，是企业数字员工与跨境电商业务工作台。React 控制台负责发现/配置员工、团队、知识、技能、SOP、工具和业务流程；FastAPI 提供身份、领域 API、对话执行与后台任务；当前开发环境约定以 PostgreSQL 为权威业务库，以 Casdoor OIDC、Casbin 和 PostgreSQL 强制 RLS 分别处理身份、操作许可和租户数据隔离。[项目记忆](../PROJECT_MEMORY.md)、[API 入口](../../src/backend/app/main.py#L84)、[前端路由](../../src/frontend-enterprise/src/App.tsx#L595)、[租户上下文](../../src/backend/app/db/database.py#L173)。

```text
浏览器 React UI
  ├─ /workspace/gallery、/workspace/chat/...：广场与对话
  └─ /enterprise/...：员工、团队、能力、业务和管理
        │ 同源 /api，携带应用会话 Cookie 或 Bearer Token
        ▼
FastAPI app.main：认证、Casbin 审计、领域路由、Worker
  ├─ /api/chat/stream → AgentLoop → HarnessV2Engine → 模型/知识/SOP/工具
  ├─ /api/enterprise/* → 领域服务 → SQLModel/SQLAlchemy
  └─ /api/v1（开关控制的公共 API）、渠道/A2A
                                      │
                                      ▼
                            PostgreSQL + RLS、仓库外运行文件与外部系统
```

“**已实现**”仅表示当前源码有页面/API/处理逻辑；“**兼容/历史**”表示保留的旧入口或旧部署说明；“**仅配置/规划/待验收**”表示代码、开关、Mock 或 PRD 尚不足以证明真实外部业务已跑通。健康端点、种子、确定性 Mock 和恢复数据库均不是生产批准。[项目记忆的验收边界](../PROJECT_MEMORY.md)、[当前交接](../SESSION_HANDOFF.md)。

## 3. 后端入口、生命周期与 API

### 一轮对话

1. 浏览器 `useChatSession` 调用 `streamChatTurn`，向 `/api/chat/stream` 发送带凭证请求并处理事件流。[useChatSession.ts:3145](../../src/frontend-enterprise/src/pages/chat/useChatSession.ts#L3145)、[client.ts:202](../../src/frontend-enterprise/src/api/client.ts#L202)。
2. 后端检查用户、请求租户、会话归属、员工可用性和附件；团队 TL 会话可以先注入团队上下文。[chat.py:1082](../../src/backend/app/api/chat.py#L1082)。
3. `AgentLoop.handle_turn_stream` 进入 Harness v2；同步 `/turn` 则经过 `AgentLoop.handle_turn` 与 `HarnessV2Engine`。引擎管理会话、任务帧、计划、工具动作、结果与恢复，并输出事件。[agent_loop.py:143](../../src/backend/app/core/agent_loop.py#L143)、[agent_loop.py:295](../../src/backend/app/core/agent_loop.py#L295)、[harness_v2_engine.py:269](../../src/backend/app/core/harness_v2_engine.py#L269)。
4. `/api/chat/sessions/*`、`/events`、`/trace` 和 `/artifacts/*` 提供历史及产物读取；取消有独立端点。[chat.py:1470](../../src/backend/app/api/chat.py#L1470)、[chat.py:1981](../../src/backend/app/api/chat.py#L1981)、[chat.py:2182](../../src/backend/app/api/chat.py#L2182)。

工作任务走异步路径：Worker 按租户领取任务、校验员工发布版本、取得租约并固化员工/SOP/能力快照，再根据 sandbox 等模式执行并记录 Run/事件/证据。Sandbox 只读回放不等于真实外部写入。[worker.py:82](../../src/backend/app/work_tasks/worker.py#L82)、[worker.py:248](../../src/backend/app/work_tasks/worker.py#L248)、[worker.py:289](../../src/backend/app/work_tasks/worker.py#L289)、[worker.py:431](../../src/backend/app/work_tasks/worker.py#L431)。

## 5. 登录、权限与租户数据边界

常规用户走 Casdoor OIDC：登录生成短期 state、PKCE challenge 和 nonce，回调交换并校验身份、映射本地用户，再设置 HttpOnly 应用会话 Cookie。仓库保留明确初始化的紧急本地管理员，`/api/auth/login` 使用应用 Bearer Token；它不是一般用户的常规生产回退路径。[oidc.py:62](../../src/backend/app/api/oidc.py#L62)、[oidc.py:111](../../src/backend/app/api/oidc.py#L111)、[auth.py:224](../../src/backend/app/api/auth.py#L224)、[项目记忆](../PROJECT_MEMORY.md)。

受保护请求由 `get_current_user` 从 Bearer 或 Cookie 读取应用令牌，检查签名/期限、租户和用户活跃状态及 `session_version`，并将租户绑定数据库 Session。企业 API 另经 `require_enterprise_permission`：Casbin 依角色、租户、路径、HTTP 方法判断，允许和拒绝都写入 `AuthorizationDecision`，审计写入失败返回 503。前端 `/api/auth/me` 能力清单用于菜单与只读体验，后端判断仍是权威。[security/auth.py:47](../../src/backend/app/security/auth.py#L47)、[main.py:180](../../src/backend/app/main.py#L180)、[authorization.py:155](../../src/backend/app/security/authorization.py#L155)、[authorization.py:185](../../src/backend/app/security/authorization.py#L185)。

PostgreSQL 事务中的 `app.tenant_id` 变量和迁移中的 `ENABLE/FORCE ROW LEVEL SECURITY` 共同形成数据层租户边界；业务资源还可能限制店铺/资产范围并要求独立审批。Casbin 通过并不能跳过 RLS 或资源授权。[database.py:173](../../src/backend/app/db/database.py#L173)、[RLS 迁移:33](../../src/backend/migrations/20260830_postgresql_tenant_rls.sql#L33)、[BusinessResourcesPage.tsx:471](../../src/frontend-enterprise/src/pages/BusinessResourcesPage.tsx#L471)。

生产启动在数据库初始化前要求 OIDC 开启、关键配置完整且 HTTPS、Secure Cookie、强 `APP_SECRET`、关闭 Demo seed。配置默认仍保留 SQLite/自动建表供开发测试，不能据此推断当前恢复环境使用 SQLite；项目约定当前开发以 PostgreSQL 为权威，正式 schema 变更走显式迁移。[runtime_config.py:27](../../src/backend/app/security/runtime_config.py#L27)、[main.py:111](../../src/backend/app/main.py#L111)、[config.py:8](../../src/backend/app/config.py#L8)、[项目记忆](../PROJECT_MEMORY.md)。
